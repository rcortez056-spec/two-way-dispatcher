# JurisAgent AI (Two-Way Dispatcher)

An autonomous multi-agent workflow system built for real-time legal intake, compliance screening, and intelligent routing.

## 🚀 Overview
JurisAgent AI streamlines regulatory and legal operations by orchestrating automated workflows. Powered by Relevance AI, the system ingests unstructured case inquiries, maps complex data payloads, and executes automated routing and qualification.

## 🛠️ Architecture & Tech Stack
* **Orchestration:** Relevance AI Multi-Agent Workflows
* **Frontend / Interface:** HTML5, CSS3, JavaScript (Deployed via GitHub Pages)
* **Core Functions:** Automated compliance screening, two-way routing, real-time intake parsing.
